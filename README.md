# さつまいもカーレース — 最小プロトタイプ

## あそぶ

**[ブラウザで遊ぶ](https://usapon-jp.github.io/sweet-potato-race/)**

ひとり用は `index.html` をブラウザで開いて遊べます。インストール・通信・ログインは不要です。2人対戦は公開URLまたはローカルサーバーで開き、インターネット接続が必要です。
ローカルサーバーで開く場合はこのフォルダで `npm start`、または `./start.command` を実行し、 http://localhost:4177 を開いてください。

- 画面は横向き専用（16:9）。縦向きでは横向き案内を表示します。回転できない場合は「ゲームをはじめる」を押すと、端末の回転設定を変えずにゲームを90度回転して表示します。
- ぽん・うさ・むぎくん・もかちゃま・ゆずくんから1匹を選択します。
- 残り4匹をランダムな順番で対戦。1対1で4勝すると優勝します。
- 負けたら同じ相手に再挑戦。すでに勝った相手には戻りません。
- 自動で右に走行。左下の ▲ / ▼ で3レーンを移動、右下でジャンプ。
- キーボード：↑ / ↓ でレーン移動、Space でジャンプ、P / Esc で一時停止・再開。
- どんぐりを取ると約2.8秒加速。接触で最大3個を落とし、約1.45秒減速します。
- 岩はジャンプまたはレーン移動で回避。ジャンプ台は自動で高く飛びます。
- 相手にもアイテム、障害物、接触が適用されます。
- 1レースはおよそ40秒。今回の野原ステージを4戦共通で使います。
- タブ切り替え・ウィンドウのフォーカス喪失時は一時停止します。

全画面ボタンは対応ブラウザで全画面化と横向きロックを試みます。OS側の向き固定を強制できないブラウザでも、縦向きでレースが進むことはありません。

### 近くの人と対戦

公開URLで「近くの人と対戦」を押し、表示されるQRコードをもう1台で読み取ります。両方が準備できたらスタートし、結果画面から同じ部屋で再戦できます。登録は不要です。公開版はMacの起動や同じWi-Fiを必要としません。

#### ローカル2台試験

これは公開操作ではありません。まず `npm test`、`npm run build`、`npm run test:serve` を順に実行します。最後のコマンドが同じWi-Fiで開けるLAN URLを表示するので、作成者の端末でそのURLを開き「近くの人と対戦」から部屋を作ります。表示したQRコードをもう1台で読み取り、両方でうさぎさんを選んで「準備できた」を押すとレースが始まります。

試験は `usapon-lab` のSupabase Realtime Broadcastだけを使います。ローカル起動コマンドで公開サイトを更新することはなく、通信先も共有メインプロジェクトとは分けています。Realtimeの利用枠は組織内で共有されるため、試験は必要な回数だけにしてください。途中で画面を隠す、縦向きにする、終了ボタンを押すとその対戦は中断されます。結果画面で両方が「もう一度あそぶ」を選ぶと、同じ部屋のまま再戦できます。結果画面のまま120秒経過した、または相手の接続が終わった場合は、新しいQRコードの部屋を作ります。

## 素材

ユーザー提供PNGのコピーを `assets/` に保存。`assets/credits.json` に元のファイル名とSHA-256を記録しています。元ファイルと画像内容は変更していません。
5匹は描画時に左右反転して右向きに表示します。顔・表情の変更や描き直しはありません。透明な余白のみ描画領域から除外しています。
背景には提供された `HP 2.png` を使用。空・雲・丘・道・草花・岩・ジャンプ台・どんぐりはCanvasで描画しています。

## ファイル

- `index.html` / `style.css`：選択、操作、結果画面
- `engine.js`：レース・接触・ジャンプ・対戦相手の処理
- `game.js`：描画、操作、勝ち抜きの画面遷移
- `tests/`：Node標準テストランナーによる回帰テスト（`npm test`）

このゲームは独立したGitHub Pagesサイトとして公開しています。進行の保存・音楽・追加ステージは含まれません。

## 公開方法

`npm test` → `npm run build` で確認し、`main` へのpushでGitHub ActionsがテストとGitHub Pagesへの公開を行います。`dist/` にはゲームに必要なファイルだけを出力します。対戦を選んだ時だけ、公開用設定で `usapon-lab` のRealtime Broadcastへ接続します。秘密キーは配信しません。

## 難易度と逆転アイテム

- 相手の通常速度は1〜4戦で278 / 286 / 294 / 300。プレイヤーは300で固定。後半ほど回避・アイテム取得判断が上手になります。
- 金色どんぐりは2戦目から2 / 3 / 4個。取得後1.5秒、通常の2倍速になります。普通の加速と重ならず、接触すると解除されます。
- 600（通常速度の約2秒分）以上離された子の先に、お助けどんぐりが落下します。対象の子のみ取得でき、普通のどんぐりと同じ加速効果があります。
- お助けどんぐりは最低6秒間隔、同時に1個、4秒で消えます。岩の近くとゴール直前には出ません。両者に同じ条件が適用されます。
- 金色は「×2」、お助けは「あなた用／相手用」と緑色の輪で区別できます。
- 落としたどんぐりの再回収は未実装です。
